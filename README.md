# Kabashi Tailoring Website

Static demo website for **Kabashi Tailoring / كباشي للخياطة الرجالية**.

## Live deployment target

This repo is ready to connect to **Render** as a Static Site.

Use these settings:

- **Service type:** Static Site
- **Build command:** leave empty
- **Publish directory:** `.`
- **Root directory:** leave empty

- Built-in JavaScript for mobile menu, reveal animation, and language toggle
